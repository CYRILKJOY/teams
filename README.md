# TaskFlow

TaskFlow is a production-grade ClickUp + Microsoft Teams Task Management System.

## Architecture
See [docs/architecture.md](docs/architecture.md)

## Development Setup

1. Copy `.env.example` to `.env` and fill in the values.
2. Run `npm install`
3. Run `npm run dev` to start the development server.

## Testing
- `npm test`

## Linting & Formatting
- `npm run lint`
- `npm run format`

## Docker
- `docker-compose up -d`
